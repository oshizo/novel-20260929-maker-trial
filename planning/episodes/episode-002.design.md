# Episode Design: 追手から姉妹を救う

## 役割と境界

- Episodeの役割:
  - 追手と魔物に襲われている姉妹をカイが見つけ、三人それぞれの判断と能力を合わせて救助する。初対面での異性としての意識、姉妹の警戒と小さな評価、利害に基づく暫定同行までを描く。
- 入口:
  - カイが林の中で追跡の痕跡をたどり、追手と魔物に襲われている二人の女性を見つける。直前Episodeの出口からこの発見までは、場面1の冒頭で描く。
- 出口:
  - 追手と魔物を退けて現場を離れた三人が、研究への疑いと追跡の危険を抱えたまま暫定同行を選ぶ。
- 視点 / 人称:
  - カイ一人称。全場面で視点を移さない。

## 登場人物の目的と変化

### カイ

- この回で望むこと:
  - 負傷者を助けたい。ただし自分が負傷して旅と訓練を続けられなくなる事態は避けたい。救助の見込みと撤退条件を確かめて行動する。姉妹の魔法と、追手が用いる魔力の扱いにも関心を持つ。
- 妨げになること:
  - 追手と魔物の数・位置が分からず、視界の悪い林では包囲の危険がある。カイは魔力総量がやや少なく、魔力知覚を長く使うと頭痛と視野狭窄が強まる。姉妹は負傷と疲労で本来の力を出せない。
- 重要な判断の参照:
  - 場面1 / 場面2 / 場面3 / 場面5 / 場面6。
- 出口までに変わること:
  - 初対面のリシェルとエルナを異性として魅力的だと意識する。姉妹の危機を見過ごさず、救助を優先する。三人の行動を組み合わせて救助を成立させる。魔力循環を研究していたグレンは知らないが、姉妹がその研究との類似を疑っていると知り、研究と二人の魔法への関心を持つ。同行が追跡の危険を伴うと理解したうえで、暫定同行を受け入れる。

### リシェル

- この回で望むこと:
  - 追手から妹を守り、二人で現場を離れる。
- 妨げになること:
  - 負傷と疲労で炎魔法の出力や持久力が落ちている。妹を守るために注意を割きながら追手の狙いも見なければならない。救助者のカイにも、父の研究との関係がないか警戒している。
- 重要な判断の参照:
  - 場面2 / 場面3 / 場面5 / 場面6。
- 出口までに変わること:
  - カイの行動を見て、妹を守る役の一部を任せる。実力と見返りを求めない態度を小さく評価するが、研究への疑いは残す。追跡を避けるためカイとの暫定同行を選ぶ。

### エルナ

- この回で望むこと:
  - 追手の位置と進路を見極め、リシェルを守りながら安全に離脱する。
- 妨げになること:
  - 負傷と疲労があり、姉を支えながら追手と魔物の動きを探る必要がある。カイが父の研究を盗んだ、または関係している可能性を捨てられない。
- 重要な判断の参照:
  - 場面2 / 場面3 / 場面5 / 場面6。
- 出口までに変わること:
  - 追跡の兆候と自分が把握している退路をカイへ共有し、次の進路判断の一部を任せる。彼の実力を小さく評価するが、研究への疑いは残す。追跡を避けるためカイとの暫定同行を選ぶ。

### 追手の指揮役

- この回で望むこと:
  - 姉妹を捕らえるか討ち、グレンの研究へつながる情報を得る。
- 妨げになること:
  - 林の中で姉妹の位置を見失いかけており、負傷者二人を相手にするつもりで、加わったカイと姉妹の連携を見誤る。
- 重要な判断の参照:
  - 場面2 / 場面3 / 場面4。
- 出口までに変わること:
  - 術者の攻撃が止まり隊列も乱れたのを見て、配下へ撤退を命じる。魔物も統制を失って退く。

## 場面順

### 場面1: 林の奥で襲撃を見つける

- 時間 / 場所:
  - 日没前。街道から外れた林の中。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - カイは足跡と血の跡をたどり、追手と魔物が二人の女性を林の窪地へ追い詰めている場面を見つける。二人は負傷して疲れているが、互いをかばいながら抵抗している。
  - リシェルは肩と腹部を見せる旅装を着ており、負傷しても腰を落としてもう一人の前へ出る。その動きには、踊りで鍛えたしなやかさが残っている。追手の視線を受けても怯まず、華やかな顔立ちを正面から向けている。エルナは肌の露出を抑えた旅装でリシェルを支え、整った顔立ちと、周囲を確かめる落ち着いた目つきが目に留まる。カイは二人の姿に異性として惹かれるが、見とれる間を置かず追手の人数、距離、退路を確かめる。
  - 追手は二人を逃がさないよう左右から回り込み、魔物を前へ出して退路を狭めている。カイは二人が抵抗を続けていること、敵の位置、道へ戻る方向を確かめる。
- 人物の判断:
  - カイは退路と敵の位置を見て、介入しても離脱できると判断する。
- この場面で明らかになる情報:
  - カイには、負傷した成人に見える女性二人が追手と魔物に囲まれかけていると分かる。二人の名前と血縁はまだ分からない。
- 感情や関係の変化:
  - カイは二人に異性として惹かれる印象を持つが、二人との関係はまだない。

### 場面2: 姉妹の知らせで包囲を避ける

- 時間 / 場所:
  - 続けて、林の窪地と周辺の木立。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - カイが横から追手へ仕掛けようとすると、エルナが風の探知で気づいた回り込みを伝える。敵の一部はカイを迎え撃つのではなく、道へ戻る退路を塞ごうとしている。彼女の知らせがなければ、カイは側面から挟まれていた。
  - エルナはもう一人の女性を姉と呼び、リシェルもエルナの名を呼ぶ。カイは二人が姉妹で、エルナと呼ばれた方が妹だと知る。
  - リシェルは妹を背に守る位置を崩さず、負傷した体で短い炎を放って追手の注意を自分へ向ける。追手がカイへ向けていた動きと隊列を一瞬乱すため、自分で選んで放つ。
  - カイは二人が作った時間を使い、剣を抜いて敵との間合いを詰める。魔物の硬い爪を剣で受けるため刃へ魔力を通し、爪を弾く。エルナは危険を見たら伝える役を続け、リシェルは無理に大きな炎を重ねず、妹を守る位置を維持する。
- 人物の判断:
  - エルナは見知らぬカイへ敵の位置を知らせる危険より、退路を塞がれる危険が大きいと考える。カイは敵を一人ずつ追うと姉妹が包囲されるため、退路を塞ぐ敵へ向かう。
- この場面で明らかになる情報:
  - 姉の名前はまだ分からない。
- 感情や関係の変化:
  - 三人は互いを信用していないが、戦闘中に相手の行動を見て動き始める。

### 場面3: 魔力の乱れを見て攻撃を止める

- 時間 / 場所:
  - 続けて、窪地から退路へ続く木立。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - 退路を塞ごうとする追手の術者が、木々の間へ攻撃を通すため魔力を集め始める。カイは一度だけ魔力知覚を集中し、集めた魔力の一部が散って、術者がまだ成形へ進めていないと感じ取る。発現までに短い遅れがあると判断するが、術の仕組みや攻撃の行き先は分からない。
  - カイは頭痛と視野の端が狭まる感覚を覚え、症状が強まる前に観察を切り上げる。エルナが伝えた術者の位置と、リシェルの炎で隊列が乱れた短い間を使う。カイは剣への魔力付与を止め、身体強化に切り替えて術者との間合いを詰める。
  - 術者が成形のために構えていた腕を、カイが剣で打つ。術者は腕を引いて身振りを続けられず、集めた魔力を攻撃へ整える前に発動を断念する。術者が退路を塞ぐ位置から退いたため、姉妹が抜ける幅が開く。カイは強化を続けず、剣技で近づいた敵を押し返す。
  - 周囲の追手と魔物は退路を塞げず、隊列を保てなくなる。姉妹はカイが魔物の爪を弾いた剣を下げ、急に踏み込んで術者へ届くところを見る。その後もカイは剣で戦い続ける。
- 人物の判断:
  - カイは症状が出始めたため、これ以上観察を続ければ戦う判断も鈍ると考える。
- この場面で明らかになる情報:
  - なし。
- 感情や関係の変化:
  - なし。

### 場面4: それぞれの力で離脱の時間を作る

- 時間 / 場所:
  - 続けて、木立から林の斜面へ。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - カイは追手と魔物の正面を引き受け、剣技と必要な瞬間の身体強化で前進を止める。魔力を連発して敵を圧倒するのではなく、数を崩し、姉妹が抜けられる幅を保つ。
  - エルナは風の探知で別方向から迫る敵を知らせ、必要な範囲へ風の支援を使って追手の動きを遅らせる。リシェルは妹と離れず、自分の判断で短い炎を重ね、追手の注意をそらして隊列をさらに崩す。負傷による消耗があり、大きな術を続ける余裕はない。
  - カイは二人の合図と動きを受け、狙う敵と退く向きを変える。追手は攻撃を続けても姉妹を再び囲めず、魔物も統制を失って退く。指揮役が配下へ撤退を命じ、追手は三人から離れる。カイには指揮役の考えまでは分からない。
  - 三人は追手が態勢を立て直す前に窪地を離れ、木立を抜ける。
- 人物の判断:
  - 追手の総数が分からないため、カイは追撃を避ける。リシェルとエルナも負傷を悪化させず離脱することを優先する。
- この場面で明らかになる情報:
  - なし。
- 感情や関係の変化:
  - なし。

### 場面5: 救助の後も疑いを解かない

- 時間 / 場所:
  - 夕刻。追手の視界から外れた林の端。
- 登場人物:
  - カイ、リシェル、エルナ。
- 起きること:
  - カイは頭痛と視野の狭まりが残るため、魔力知覚を使い直さない。周囲の音を聞き、道へ戻る目印を確かめる。見える範囲に追手はおらず、近くから物音も聞こえないが、戻ってこないとは決めつけない。姉妹も消耗しているが、カイから距離を取り、武器を手元に置いたまま話す。
  - エルナは、カイが魔物の爪を弾いた後で剣を下げ、急に踏み込んだことを尋ねる。カイは、剣へ魔力を通して爪を弾き、術者へ向かうとき付与を止めて身体強化へ切り替えたと説明する。
  - リシェルとエルナは、カイが魔法を短く切り替えても戦い続けた様子を、幼い頃に父グレンから教わった余剰魔力を体内へ戻す訓練と比べる。二人は、戦い方からカイの魔力循環が父の研究と似ているのではないかと疑う。体内の魔力の流れを直接知覚したわけではなく、外から見えた動きとカイの説明を手掛かりにしていると伝える。似ている理由も分からない。
  - リシェルは自分の名を告げる。二人はカイがグレンを知っているのか、研究を盗んだのかを問う。
  - カイはグレンと面識がなく、研究を盗んだ覚えもないと答える。研究のことは知らなかったが、姉妹の魔法と父の研究には関心を持つ。救助の見返りに情報や感謝を求めず、負傷の手当てや次の移動を優先する。
  - リシェルは、カイが自分の炎で生まれた隙を使い、強化を長引かせず術者の攻撃を止めた理由を尋ねる。妹を危険へ押し出さず、自分の判断も妨げなかった点も挙げ、次の移動では妹を守る役の一部を彼に任せると言う。
  - エルナは、術者への踏み込みの時機をどう選んだか尋ねる。カイは、術者が集めた魔力の一部を失い、攻撃を放つまでに遅れがあると感じたと説明する。エルナは自分が知らせた回り込みの位置と彼の説明を比べ、彼が魔力を使い切らず退路を開いたと認める。父の研究との類似は解けないまま、追跡の兆候と把握している退路を共有し、進路判断の一部を彼に任せる。二人とも警戒と疑いは明言して保つ。
- 人物の判断:
  - カイは同行の話を急がせず、二人が危険を避けるために彼を使う場合の役割と限界を話し合う。リシェルとエルナは、救助を理由に信頼や好意を与えるのではなく、見た行動を基に必要な範囲だけ任せる。
- この場面で明らかになる情報:
  - なし。
- 感情や関係の変化:
