# 執筆指示: 記憶が戻った日

## 視点 / 時系列 / 場所

- 視点 / 人称:
  - カイ一人称。前世の記憶も、現在のカイが思い出している経験として書く。
- 時間:
  - 場面1は日中。場面2は場面1からしばらく後の夜。場面3は記憶が戻った後、熱が下がってから。
- 場所:
  - 場面1はカイの家。場面2は自宅の寝床。場面3はカイの家の中。
- 視点切替:
  - なし。看病する家族の考えや、カイが知らないことは書かない。

## 入口と出口

### 入口

- 十代半ばのカイは、家族が使う戸の留め具がうまく掛からないことに気づいている。

### 出口

- 熱が下がったカイは、同じ場所で灯火の魔法を二度試す。
- 二度目は、魔力が集まり始めてから灯りがつくまでの時間が一度目より短いように感じるが、理由は分からない。
- カイはこの日の試行を終え、体調が戻った後に同じ条件で比べ直そうと考える。魔法の仕組みを学び、自分の技術を磨くことを目標にする。

## 登場人物が知っていること

### カイ

- 知っていること:
  - 場面1では、家族が戸を何度も押し引きして留め具を掛け直している。
  - 場面2で記憶が戻った後、前世では現代日本の高校生として暮らし、同じクラスの友人と道具を直した経験があると思い出す。
  - 今世で身近な初歩の灯火の魔法を使ってきた。
- 知らないこと:
  - 戸の留め具が再びずれないか、長く使った後の耐久性。
  - 灯火の魔法が働く仕組み。
  - 場面3では、二度の試行で感じた灯りがつくまでの時間差が、息を吐く速さによるものか、熱の後で感覚が不安定なためか分からない。

### 家族

- 知っていること:
  - 戸の留め具がうまく掛からず、カイが直そうとしている。
  - カイが熱を出して寝込み、看病を受けている。
- 前世の記憶について、家族が知っているとは扱わない。

## 視点人物の内部状態

### 場面1

- 欲求 / 意図:
  - 戸を使う家族の不便をなくしたい。
- 判断:
  - 原因を確かめる前に戸を削ると、家族をさらに困らせるかもしれない。
  - 手元の材料は必要な分だけ使う。
  - 修理が長く持つかはまだ分からない。
- 感情:
  - 自分の工夫で家族の手間が減ったと感じる。

### 場面2

- 記憶 / 感情:
  - 熱で眠ったり目を覚ましたりする中、日本で暮らした前世の記憶がまとまって戻る。
  - 高校の放課後、友人のシャープペンシルが詰まり、芯の通り道を一緒に確かめて直した日のことを思い出す。
  - 直ったときに友人が安堵して笑ったことや、帰り道を一緒に歩いたことを懐かしく感じる。
  - 家族の声を聞き、今世の家族と過ごした日々や、戸を直して喜ばれたことを意識し、家族がそばにいることに安堵する。
- 判断:
  - 前世と今世は同じ人生ではない。
  - どちらかを偽物として退けず、今世を生きる自分が別の人生の記憶も持つようになったと受け止める。

### 場面3

- 欲求 / 意図:
  - 灯火の魔法で起きることを確かめたい。
  - 魔法の仕組みを学び、自分の技術を磨きたい。
- 記憶 / 疑念 / 推測:
  - 前世で友人と道具の詰まりを確かめた記憶から、魔法にも確かめられる違いがあるのではないかと思う。
  - 二度目は、魔力が集まり始めてから灯りがつくまでの時間が一度目より短いように感じる。息の速さが原因とは決められない。熱の後で感覚が不安定な可能性もある。
- 判断:
  - 前世の知識を当てはめても、灯火の魔法が働く仕組みは説明できない。
  - 体調が戻った後、同じ条件で比べ直す。

## 場面で必ず起こること

### 場面1: 戸の留め具を直す

- 人物:
  - カイ、戸を使う家族。
- 必ず起こる行動・発話内容・事実:
  - カイは家族に、誰がどんな時に戸で困るのかを尋ねる。
  - 戸を動かして、留め具の掛け金が戸枠の受け金具からどう外れるかを確かめる。
  - 受け金具が少し動くと掛け金が外れると分かる。カイが受け金具の位置を直しても、戸を何度か動かすうちに再びずれる。
  - 受け金具を外すと、固定ねじの穴が広がっている。カイは手元の細い木片を穴に差し、同じねじで受け金具を固定し直す。
  - カイと家族は戸を使って、留め具が掛かる状態に戻ったことを確かめる。
  - 家族は使えるようになったことを喜ぶ。
- 情報が明らかになる時期:
  - 受け金具のねじ穴が広がっていることは、受け金具を外した後に分かる。

### 場面2: 熱の夜に前世を思い出す

- 人物:
  - カイ。家族は看病のため近くにいる。
- 必ず起こる行動・発話内容・事実:
  - カイは熱で眠ったり目を覚ましたりする。
  - 前世の記憶がまとまって戻る。高校の放課後に友人のシャープペンシルを一緒に直したことと、その友人と過ごした時間を思い出す。
  - 目覚めたカイのそばに家族がいる。家族が熱の具合を尋ね、カイは返事をして差し出された水を受け取る。
  - 前世の記憶で混乱していたカイは、家族の声を聞いて、今世で家族と過ごした日々を思い出す。記憶の混乱が少し落ち着いてから、前世の友人と今世の家族を順に思い浮かべる。
- 情報が明らかになる時期:
  - 前世の記憶は、カイが熱で眠ったり目覚めたりしている間に戻る。
  - 前世の記憶を持つようになったことはカイの内面で起きる。家族に明かす場面はない。

### 場面3: 灯火の魔法を二度試す

- 人物:
  - カイ。
- 必ず起こる行動・発話内容・事実:
  - 熱が下がった後、まだ本調子ではないカイが家で休んでいる。カイは身近な初歩の灯火の魔法を見直す。
  - カイは同じ場所で同じ灯火の魔法を二度使う。一度目はいつもの呼吸で発動し、魔力が集まり始めてから灯りがつくまでを意識する。
  - 二度目は息を吐く速さだけを変え、魔力が集まり始めてから灯りがつくまでの時間を比べる。二度目の時間は一度目より短いように感じられるが、その原因は判別できない。
  - カイは灯りを消して、この日の試行を終える。
- 情報が明らかになる時期:
  - カイが魔力の流れと、魔力が集まり始めてから灯りがつくまでの時間を意識するのは、記憶が戻った後の試行中。
  - 二度の試行で感じた違いの理由は、このEpisode内では明らかにならない。

## 身体・物・環境の事実

- 戸の留め具は、戸の掛け金と戸枠の受け金具でできている。
- 受け金具の固定ねじの穴は広がっており、細い木片を差して同じねじで固定し直す。
- カイは熱を出して寝込み、場面3では熱が下がっているが本調子ではない。
- 前世の記憶にある道具はシャープペンシル。詰まった芯の通り道を友人と確かめて直した。
- 灯火の魔法はカイが家の中で使ってきた初歩の魔法である。

## 継続上の必須条件

- 全編をカイ一人称で描き、前世の出来事もカイの記憶として扱う。
- 戸の修理は、受け金具を固定するねじ穴が広がっていたために行う。原因を確かめず戸を削ったことにはしない。
- 戸の修理が長く持つかは確かめていない。ずっと持つと断定しない。
- カイが二度の試行で感じた、灯りがつくまでの時間差の原因は確定しない。熱の後で感覚が不安定な可能性を残す。
- 家族の内面へ視点を移さず、前世の記憶を知ったと決めつけない。
- 灯火の魔法の仕組みを、カイが確かめていない知識として説明しない。
- 出口では、二度の試行を終えたカイが、感じた違いの理由をまだ知らない状態を保つ。
