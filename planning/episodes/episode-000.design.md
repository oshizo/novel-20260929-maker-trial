# Episode Design: 記憶が戻った日

## 役割と境界

- Episodeの役割:
  - 記憶覚醒前の今世のカイから、日本での前世のカイを経て、記憶を得た後に魔法を学ぶ目的を持つカイまでを描く。Arc冒頭の導入Episodeとして、家族との暮らしの中で育ったカイの判断と、二つの人生を自分のものとして受け止める過程を読者に伝える。
- 入口:
  - 十代半ばのカイが家族の使う戸の留め具の不具合に気づき、困りごとを聞いて原因を探り、直し方を試し始める。
- 出口:
  - カイは灯火で炎が現れる前に魔力の流れ方が変わることに気づく。まだ理由は分からないまま、次に比べる条件を決める。技術を磨く目的への変化は「登場人物の目的と変化 > カイ > 出口までに変わること」を参照。
- 視点 / 人称:
  - カイ一人称。記憶覚醒前も後も同じカイの経験として語る。日本での前世の場面も、覚醒時にカイが思い出す記憶として示す。

## このEpisodeで読者に楽しませること

### 前世と今世を自分のものとして受け止め、魔法を学ぶカイ

- 読者が楽しめること:
  - 読者は、記憶が戻る前から家族のために自分で考えて行動するカイと、日本で相手の話を聞いて判断を変えたカイの両方を知る。記憶が戻った直後にも今世の家族へ応じ、その後に二つの人生を自分のものとして受け止める変化を楽しめる。
  - カイが日常の魔法に以前は気づかなかった魔力の動きを見つけ、まだ理由を説明できないまま次に比べる条件を選ぶ。仕組みが少し見えたことで、読者も魔法をカイと一緒に観察し始める楽しさを得る。

## 後の楽しさのために、このEpisodeで先に示すこと

### 魔力を理解し、試行錯誤で身につけるカイ

- 後で楽しませたいこと:
  - カイが魔力の流れや術式の仕組みを読み、理解した内容を練習と実戦で役立つ技術へ変えていく知的な攻略と、限られた魔力を工夫して使う有能さを読者が楽しめる。
- このEpisodeで先に理解させること:
  - 前世の知識を魔法へそのまま当てはめても答えにはならない。魔力の流れを感じ取れても、それだけでは作用の理由を説明できず、観察する範囲を絞って試し直す必要がある。

## 登場人物の目的と変化

### カイ

- この回で望むこと:
  - 場面1では、家族の戸を使えるようにし、直したことでかえって家族へ余計な手間をかけないようにしたい。記憶覚醒後は、前世の自分の記憶と今世の家族や経験を、自分の人生の一部として受け止めたい。魔法については、前世の知識で分かったふりをせず、自分が見つけた疑問を確かめたい。
- 妨げになること:
  - 留め具の不具合は一見しただけでは原因が決まらず、直した後も長く使えるかはまだ分からない。高熱の夜に戻った前世の記憶は、今世の家族や生活の実感とは異なる経験を含んでおり、思い出した直後にその関係を整理できない。魔力の流れを感じても、作用の仕組みすべてが分かるわけではない。
- 重要な判断の参照:
  - 場面1、場面3、場面4。
- 出口までに変わること:
  - 今世の家族への愛着を保ったまま、日本での前世を自分の経験として受け止める。二つの人生には違いがある一方、仕組みを知りたい好奇心は共通していると考える。魔法を仕組みから学び、観察して試すことで技術を磨く目的を持つ。

### カイの家族

- この回で望むこと:
  - 戸を普段どおり使い、留め具の不具合による手間を減らしたい。
- 妨げになること:
  - 留め具がうまく掛からず、戸を閉めるたびに位置を直す必要がある。
- 重要な判断の参照:
  - なし。
- 出口までに変わること:
  - 戸を使えるようになり、留め具を掛けるときの手間が減る。

## 場面順

### 場面1: 留め具を確かめて直す

- 時間 / 場所:
  - カイが十代半ばの頃。家族の家の戸口。
- 登場人物:
  - カイと家族の一人。
- 起きること:
  - カイは家族が戸を何度も押し引きして留め具を掛け直しているのを見て、誰がどんなときに困るのか尋ねる。
  - 家族は、戸が少しずれると留め具が合わず、手で戸を押さえながら掛けることがあると説明する。カイは家族が使っているところを見て、戸を閉める位置と留め具のずれを確かめる。
  - カイは戸枠や留め具をいきなり削らず、まず留め具を支える部分の緩みを確かめ、手元にある小さな木片を挟んで位置を調整する。戸を何度か開閉し、家族にもいつもの使い方をしてもらう。
  - 留め具が通常の使い方で掛かることを確かめ、家族の手間が減ったと分かる。カイはこの試し方で使えるようになったとは言うが、長く持つかまでは分からないと伝える。
- 人物の判断:
  - カイは、家族の使い方を見てから原因を判断する。手元の物を無駄にせず、元へ戻せる調整から試す。耐久性についてはまだ判断しない。
- この場面で明らかになる情報:
  - 記憶覚醒前のカイにも、家族のために自分で考えて行動する習慣がある。
- 感情や関係の変化:
  - 家族はカイに困っていることを説明し、カイは自分の工夫が暮らしの役に立ったと感じる。

### 場面2: 高熱の夜に前世を思い出す

- 時間 / 場所:
  - 場面1の後。体調を崩して寝込んでいるカイの寝床。
- 登場人物:
  - カイ。現在の家族の一人は寝床でカイに声をかける。日本の同級生はカイが思い出す記憶の中に登場する。
- 起きること:
  - 高熱で眠ったり目覚めたりする中、カイは日本の家族との暮らしや高校生活を断片的に思い出す。
  - 高校時代、同級生から傘の開閉が引っかかると相談された記憶が戻る。カイは最初、傘の骨が曲がっていると疑う。同級生から開くときだけ引っかかると聞き、動きを一緒に確かめる。布が留め具に挟まっていると分かり、骨を曲げずに布を外す。同級生が傘を開閉し、引っかかりがなくなったのを確かめて礼を言う。
  - 記憶が途切れて目を覚ましたカイは、今の身体と家の様子を確かめる。家族が水や食事を気遣い、いつもの呼び名で声をかける。カイは声の主を家族として認識し、いつもどおり返事をする。前世の記憶にある人や場所と今の暮らしとの違いに戸惑う。
- 人物の判断:
  - カイは覚醒直後に、二つの人生の関係について結論を急がない。
- この場面で明らかになる情報:
  - 前世での暮らしと、傘について相手の話を聞いて判断を変えた経験は「起きること」を参照。
- 感情や関係の変化:
  - カイは前世の記憶に戸惑うが、今世の家族を他人とは感じない。家族への応答は「起きること」を参照。

### 場面3: 二つの人生を自分のものとして受け止める

- 時間 / 場所:
  - 熱が下がり、カイが家で休んでいる日。
- 登場人物:
  - カイと家族の一人。
- 起きること:
  - 熱が下がってから、家族がカイの体調を気遣って水を持ってくる。カイは受け取り、礼を言う。
  - カイは高熱の夜に家族へいつもどおり返事をしたことを思い返し、前世と今世の記憶を比べる。家族、身体、育った環境は異なるが、物事の仕組みを知りたい気持ちは両方の人生にあったと気づく。
  - カイは前世の記憶を家族に詳しく説明して理解を求めるのではなく、まず自分の中で整理する。
- 人物の判断:
  - カイは、今世の自分が生きてきた年月に前世の記憶が加わったのだと考える。今世で家族と過ごした経験も前世の記憶も、自分のものとして受け入れる。
- この場面で明らかになる情報:
  - 二つの人生の違いと共通点は「起きること」を参照。
- 感情や関係の変化:
  - カイには戸惑いが残るが、家族と過ごしてきた時間への親しみは続いている。二つの人生の受け止め方は「人物の判断」を参照。

### 場面4: 魔法の流れを確かめる

- 時間 / 場所:
  - 体調が戻った後。家の中で、カイが普段から触れている基本の魔法を試せる場所。
- 登場人物:
  - カイ。
- 起きること:
  - 前世の知識なら魔法の仕組みも説明できるのではないかと考えたカイは、日常で使ってきた第一位階の灯火を使い、魔力の流れを確かめる。これまでは手を動かすとすぐ灯る一つの動きとして意識していたが、今回は魔力が手の内側に集まった後、指先へ細く流れ、炎が現れる前に流れ方が変わることに気づく。
  - カイには、どの段階で炎の形が決まるのか、魔力の流れ方と明るさがどう関係するのかは分からない。前世で知った知識をそのまま当てはめても答えにはならない。
  - カイは手の位置と呪文を同じにして、次は魔力を集める速さだけを変えたとき、指先へ流れるまでの時間や灯火の様子がどう変わるか比べようと決める。その違いはまだ試しておらず、結果を決めつけない。身近な魔法にも確かめる余地があると分かり、観察して試すことを続けて自分の技術を磨こうと決める。
- 人物の判断:
  - カイは、魔力の流れを感じ取れても灯火の仕組みを理解したとは考えず、次は一つの条件だけを変えて比べる。
- この場面で明らかになる情報:
  - 灯火の観察結果と、まだ分からないことは「起きること」を参照。
- 感情や関係の変化:
  - カイは、前世の知識で答えが出るという期待を改める。灯火に新しい疑問を見つけ、自分で次の比較条件を決められたことに手応えを得る。

## 作者側の意図・設計理由

- 場面2と場面3を分けるのは、高熱で記憶が戻った直後には結論を出せないカイが、熱が下がってから二つの人生について考える時間を設けるため。
- 灯火の観察で比較の結果まで出さないのは、仕組みを知るために試し、技術を身につける過程を次Episode以降にも残すため。
