# Episode Design: 追手から姉妹を救う

## 役割と境界

- Episodeの役割:
  - 姉妹の働きとカイの判断で救助を成立させ、互いの疑いと事情を残した三人の暫定同行を始める。
- 入口:
  - カイが林の脇道を進み、追手が向かった奥の開けた場所へ近づく。負傷者の姿と身元はまだ見えていない。
- 出口:
  - 追手と魔物を退けたカイ、リシェル、エルナが暫定同行を選び、街道を避けて次の移動を始める。
- 視点 / 人称:
  - カイ一人称。

## 後の楽しさのために、このEpisodeで先に示すこと

### カイが姉妹の魔法を観察し、改善の助言をするための前提

- 後で楽しませたいこと:
  - カイが仲間の魔力操作を観察し、本人が試して身につけられる助言を作り、姉妹が自分の長所を実戦で伸ばす姿を読者が楽しめる。
- このEpisodeで先に理解させること:
  - カイは姉妹の魔法を一度見ただけで仕組みまで理解するのではなく、発動の様子と結果を観察できる段階にある。助言だけで技術は身につかず、本人の試行と反復が必要である。
- 実際に示す場面:
  - 場面3、場面4。
- 次に扱う範囲:
  - arc-02以降。

### 姉妹が警戒を保ちながら相手を見極めること

- 後で楽しませたいこと:
  - 他の男性から好意や誘いを受ける姉妹が、自分たちの意思でカイへ相談し、頼り、近くにいることを選ぶ特別扱いを読者が楽しめる。
- このEpisodeで先に理解させること:
  - 姉妹は救助されたからといって疑いを解かず、カイがどう振る舞うかを見て自分たちで判断する。今回の小さな評価は、今後の特別扱いが救助の借りではなく、二人がカイの価値を知って選ぶものだと理解する前提になる。

## 登場人物の目的と変化

### カイ

- この回で望むこと:
  - 追手と魔物に襲われている負傷者を助けたい。ただし、相手と敵の数や動きが分からないまま無謀に突入せず、退路を残して助ける。
- 妨げになること:
  - 林の奥は見通せず、最初に見えた二人以外の敵がいる可能性がある。討伐後の消耗は残り、魔力総量も多くない。魔力知覚を長く使うと頭痛と視野狭窄で判断が鈍る。
- 重要な判断の参照:
  - 場面1、場面2、場面3、場面4、場面5。
- 出口までに変わること:
  - 追手の魔法の兆候を一度の集中した知覚で捉え、頭痛と視野狭窄が悪化する前に切り上げる。姉妹の魔法は発動時の動きと結果を見たが、仕組みまでは分からない。
  - 姉妹を異性として魅力的だと意識しながら、救助の見返りを求めない。姉妹の警戒と研究への疑いを受け止める。二人の魔法とグレンの研究に関心を持ち、追跡に巻き込まれる危険を理解して暫定同行を選ぶ。

### リシェル

- この回で望むこと:
  - 追手を退けて妹を守る。初対面のカイを近づけてよいか自分で見極める。
- 妨げになること:
  - 逃走で疲労し負傷しており、炎の大きな魔法は消耗と制御の危険が高い。エルナも負傷しているため、自分が注意を引く間の判断が必要になる。
- 重要な判断の参照:
  - 場面3、場面4、場面5。
- 出口までに変わること:
  - カイの魔力循環が父の研究に似ていると疑い、信用は保留する。それでもカイの戦闘での判断と見返りを求めない態度を評価し、妹を守る役の一部を任せて暫定同行を選ぶ。

### エルナ

- この回で望むこと:
  - 追手の回り込みを見つけて姉を守る。初対面のカイが危険な相手か見極める。
- 妨げになること:
  - 姉を支えて逃げた疲労と負傷があり、探知や支援へ使える魔力にも限りがある。知らないカイへ情報を渡すこと自体にも危険がある。
- 重要な判断の参照:
  - 場面3、場面4、場面5。
- 出口までに変わること:
  - カイの技術への疑いと警戒を保つ。それでも彼の戦闘での判断と見返りを求めない態度を評価し、追跡の兆候と退路を共有して次の進路判断の一部を任せ、暫定同行を選ぶ。

## 場面順

### 場面1: 林の奥で負傷者を見つける

- 時間 / 場所:
  - 夕方。episode-001の場面4から続き、林の脇道を進んだ先。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - カイは木立の向こうの物音を追い、林の小さな開けた場所で、負傷した二人の女性が魔物と武器を持つ男たちに追い詰められているところを見る。二人には傷があり、互いを支えながら動いている。
  - リシェルは肩や背中、腹部、脚を見せる旅装を着ている。疲れた様子でも堂々と相手をにらみ、華やかな顔立ちとしなやかな身体が目に入る。エルナは露出を抑えた旅装で、整った顔立ちと落ち着いた目つきが印象に残る。カイは二人を魅力的な成人女性だと短く意識するが、すぐ追手と魔物の位置、二人の負傷、逃げ道を確かめる。
  - 高所から見た二人の追手が、開けた場所の正面から姉妹に近づく。一人は魔法を使う男で、もう一人は武器を構えている。林の奥から現れた三人目は、姉妹が逃げられる斜面側へ回り込む。魔物も正面から迫る。カイはさらに敵がいないか周囲の足音と木立を確かめる。
  - リシェルはカイを味方と決めず、エルナを背後へかばったまま、助けるつもりか短く確かめる。カイは敵を止めるつもりだと答え、二人に負傷の程度と動けるかを尋ねる。救助の見返りは求めない。
- 人物の判断:
  - 上記「起きること」の、カイが負傷者を見て救助へ入り、リシェルが妹をかばって応答する箇所を参照。
- この場面で明らかになる情報:
  - 上記「起きること」の、二人の負傷と追手三人の位置を参照。カイには姉妹が普段どれほど戦えるかはまだ分からない。
- 感情や関係の変化:
  - なし。

### 場面2: 追手の位置と退路を確かめる

- 時間 / 場所:
  - 夕方。林の開けた場所と、その外周。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - カイは姉妹と正面の追手の間に入る。開けた場所の端には、街道側へ下る斜面と木立がある。斜面へ回る三人目を止め、姉妹が下りられる幅を作ろうとする。
  - エルナは負傷したまま風の探知を短く使う。葉や枝の揺れと足音から、三人目が斜面側へ近づく位置を確かめ、カイとリシェルに伝える。探知から敵の意図や身元までは分からない。
  - カイは追手の人数と位置を目で確かめ、エルナの報告と照らす。まだ見えていない敵がいないか木立も見て、姉妹が動ける斜面への道を確かめる。
- 人物の判断:
  - 上記「起きること」の、カイが通常の観察で退路を確かめ、エルナが探知した位置を知らせる箇所を参照。
- この場面で明らかになる情報:
  - 上記「起きること」の、エルナの探知で分かる範囲を参照。
- 感情や関係の変化:
  - 登場人物の目的と変化 > エルナを参照。

### 場面3: 姉妹の行動で反撃の機会を作る

- 時間 / 場所:
  - 夕方。林の開けた場所。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - 斜面側へ回り込んだ三人目の追手が姉妹へ近づく。エルナは風でその男の足元の落ち葉を散らし、位置をカイとリシェルへ知らせる。弱い風で男の武器の狙いも外し、斜面へ出る道を塞がせない。負傷しているため、支援を続ければ消耗が増す。
  - リシェルは自分で敵の注意を引くと決め、大きな炎を避けて短い炎を正面の追手二人の足元へ放つ。正面の二人と魔物が彼女を見る。カイは二人の追手が足を止めた間に、魔法を使う男へ近づける。カイはリシェルの炎が出る様子と追手の動きが変わった結果を見るが、炎の魔力操作までは理解できない。
  - 魔法を使う男が腕を上げる。カイはエルナの風、リシェルの炎、それに対する追手の動きが見える間に、一度だけ魔力知覚を集中させる。男に魔力が偏って集まり、発動直前に乱れるのを感じるが、術式までは分からない。頭痛と視野の狭まりが始まるため、カイは知覚を切り、その後は再開しない。
  - カイは先ほど感じた乱れと、今見える男の腕の動きから発動が近いと判断する。剣へ短く魔力を通し、男の武器と腕を押し戻して発動を妨げる。エルナの風によって三人目の足が止まらなければ、カイはこの男へ踏み込めなかった。
  - カイは剣への魔力付与を止め、すぐ身体強化へ切り替える。斜面側の三人目が姉妹へ向かい直す前に踏み込み、剣でその武器を受け流す。リシェルとエルナは、剣に通っていた魔力の光が消え、カイの踏み込みが速くなる様子を見る。エルナの風の発動と男の狙いが外れた結果もカイには見えるが、その仕組みはまだ分からない。
- 人物の判断:
  - 上記「起きること」の、リシェルが短い炎を選び、エルナが三人目の追手を妨げ、カイが魔法を使う男から三人目へ対処を切り替える箇所を参照。
- この場面で明らかになる情報:
  - 上記「起きること」の、カイが目で見た姉妹の魔法の発動と結果、姉妹が見たカイの切替を参照。
- 感情や関係の変化:
  - 登場人物の目的と変化 > リシェル、エルナを参照。

### 場面4: 追手と魔物を退ける

- 時間 / 場所:
  - 夕方。林の開けた場所から街道側へ続く斜面。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - 正面にいた二人目の追手がカイの背後から姉妹へ近づく。同時に魔物がリシェルへ飛びかかる。エルナは風で魔物の踏み込みを少しずらす。リシェルは身を引き、短い炎で魔物の進路を斜面から林側へそらす。カイは風が出てから魔物の着地点が変わり、炎を避けて向きを変えるのを見る。姉妹がどのように魔力を操ったかはまだ判断できない。
  - カイは剣で魔物の攻撃を受け流し、背後へ回った二人目の追手に向き直る。男の武器が姉妹へ届く前に踏み込み、剣でその武器を横へ払う。男は腕を引いて開けた場所の中央へ下がる。カイは男を追わず、姉妹と斜面の間に残る。
  - 最初に魔法を使おうとした追手は中央で腕を上げ直す。カイは腕の動きから再度の攻撃を察し、短い牽制魔法で狙いを外す。魔力知覚は再開しない。男は離れた位置からすぐには斜面へ回れない。
  - 三人目の追手は斜面の縁を塞ごうとする。エルナは男の位置をカイへ知らせ、短い風を男の足元へ当てる。男は斜面の不安定な地面で踏み出せない。カイは姉妹と男の間に立つ。リシェルは自分で妹を連れて斜面側へ進み、残る力で短い炎を三人目の追手の前へ放つ。男は炎を避けて林側へ下がる。魔物も先の炎とカイの剣を避けて林の奥へ退く。
  - 姉妹が斜面を下り、カイも後ろを警戒しながら続く。中央へ下がった二人目は武器を構え直しており、最初の男は中央から斜面まで距離がある。三人目は風と炎で斜面の縁から離れた。追手は三人とも、姉妹が下る間に退路を塞げない。
  - カイには知覚による頭痛が残り、姉妹も負傷している。カイは追手を深追いせず、街道側の見通しを確かめて現場から距離を取る。追手がなお近くにいる可能性は残る。
- 人物の判断:
  - 上記「起きること」の、三人が斜面への道を作り、カイが追手を追わず現場を離れる箇所を参照。
- この場面で明らかになる情報:
  - 上記「起きること」の、追手三人と魔物が斜面を塞げなくなる経過、およびカイの観察範囲を参照。
- 感情や関係の変化:
  - なし。

### 場面5: 疑いを残して同行を選ぶ

- 時間 / 場所:
  - 夕方から夜。林から離れた、街道を見張れる場所。
- 登場人物:
  - カイ、リシェル、エルナ。
- 起きること:
  - 追手の姿が見えない場所で三人は短く休む。カイは頭痛を隠さず、一度の集中した知覚で負担が出たことと、今すぐ追手を追う余裕がないことを話す。姉妹の傷を確かめ、二人が許す範囲で手当てをする。
  - リシェルは、カイが剣への魔力付与を止めてすぐ身体強化へ移り、その後も短い魔法を使って戦い続けたのを見たと話す。幼い頃、父グレンから余った魔力を体内へ戻して次の術へ使う訓練を受けたこともカイへ伝える。エルナも戦闘中の切替を見たと言い、父の研究に似ているのではないかと尋ねる。二人が見たのは戦闘中の切替で、カイの体内の魔力を知覚したわけではないとカイにも伝える。似ている理由もまだ分からない。
  - 姉妹はカイに、グレンを知っているのか、研究を見たことがあるのかを問いただす。カイはグレンと面識がなく、研究を盗んでいないと答える。魔力循環は自分の試行で身につけたものだと説明するが、姉妹はすぐには信じない。
