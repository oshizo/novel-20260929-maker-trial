# Episode Design: 追手から姉妹を救う

## 役割と境界

- Episodeの役割:
  - 追跡と魔物の脅威にさらされた姉妹を、カイが二人の働きを使って救助する。戦闘後、三人が疑いと別々の事情を保ったまま暫定同行を選ぶ。
- 入口:
  - 林の脇道から進んだカイが、追手と魔物に襲われている負傷者を見つける。
- 出口:
  - 追手と魔物を退けた三人が、現場を離れて次の移動へ入る。
- 視点 / 人称:
  - カイ一人称。

- 読者が楽しめること:
  - 読者は、魔力の総量が少なく知覚にも負担があるカイが、剣技を軸に短い魔法を使い、敵の動きと魔力の乱れを結びつけて危機を切り抜ける有能さを楽しめる。姉妹が作った機会を使って追手を退けた結果を見て、二人が疑いを残しながらもカイの判断と実力を小さく評価する満足も得られる。

## 後の楽しさのために、このEpisodeで先に示すこと

### カイが姉妹の魔法を観察し、改善の助言をするための前提

- 後で楽しませたいこと:
  - カイが仲間の魔力操作を観察し、本人が試して身につけられる助言を作り、姉妹が自分の長所を実戦で伸ばす姿を読者が楽しめる。
- このEpisodeで先に理解させること:
  - カイは姉妹の魔法を一度見ただけで仕組みまで理解するのではなく、発動の様子と結果を観察できる段階にある。助言だけで技術は身につかず、本人の試行と反復が必要である。
- 実際に示す場面:
  - 場面3、場面4。
- 次に扱う範囲:
  - arc-02以降。

### 姉妹が警戒を保ちながら相手を見極めること

- 後で楽しませたいこと:
  - 他の男性から好意や誘いを受ける姉妹が、自分たちの意思でカイへ相談し、頼り、近くにいることを選ぶ特別扱いを読者が楽しめる。
- このEpisodeで先に理解させること:
  - 姉妹は救助されたからといって疑いを解かず、カイがどう振る舞うかを見て自分たちで判断する。今回の小さな評価は、今後の特別扱いが救助の借りではなく、二人がカイの価値を知って選ぶものだと理解する前提になる。

## 登場人物の目的と変化

### カイ

- この回で望むこと:
  - 追手と魔物に襲われている負傷者を助けたい。ただし、相手と敵の数や動きが分からないまま無謀に突入せず、退路を残して助ける。
- 妨げになること:
  - 林の奥は見通せず、最初に見えた二人以外の敵がいる可能性がある。討伐後の消耗は残り、魔力総量も多くない。魔力知覚を長く使うと頭痛と視野狭窄で判断が鈍る。
- 重要な判断の参照:
  - 場面1、場面2、場面3、場面4、場面5。
- 出口までに変わること:
  - カイは追手を退けた後も救助の対価を求めず、姉妹が示した警戒と研究への疑いを受け止める。姉妹の魔法とグレンの研究に関心を持ち、同行に伴う危険を確かめたうえで暫定同行を選ぶ。

### リシェル

- この回で望むこと:
  - 追手を退けて妹を守り、父の研究に関わる疑いを持つカイを近づけるか、自分で見極める。
- 妨げになること:
  - 逃走で疲労し負傷しており、炎の大きな魔法は消耗と制御の危険が高い。エルナも負傷しているため、自分が注意を引く間の判断が必要になる。
- 重要な判断の参照:
  - 場面3、場面4、場面5。
- 出口までに変わること:
  - カイを信用せず、魔力循環の類似への疑いも保つ。それでもカイが助けた見返りを求めないことと戦闘での判断を見て、妹を守る役の一部を任せ、暫定同行を選ぶ。

### エルナ

- この回で望むこと:
  - 追手の回り込みを見つけて姉を守り、研究に似た魔力運用をするカイの意図と危険性を見極める。
- 妨げになること:
  - 姉を支えて逃げた疲労と負傷があり、探知や支援へ使える魔力にも限りがある。知らないカイへ情報を渡すこと自体にも危険がある。
- 重要な判断の参照:
  - 場面3、場面4、場面5。
- 出口までに変わること:
  - カイへの疑いを残しながら、戦闘中に自分が得た情報を彼へ伝える。追跡を避ける手段として、次の進路判断の一部をカイに任せて暫定同行を選ぶ。

## 場面順

### 場面1: 林の奥で負傷者を見つける

- 時間 / 場所:
  - 夕方。episode-001の場面4から続き、林の脇道を進んだ先。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - カイは木立の向こうから聞こえる物音を追い、林の小さな開けた場所で、負傷した二人の女性が魔物と武器を持つ男たちに追い詰められているところを見る。二人の傷や疲労は、逃げてきた跡と、互いを支えながら動いている様子から分かる。
  - リシェルは肩や背中、腹部、脚を見せる旅装を着ている。疲れた様子でも堂々と相手をにらみ、華やかな顔立ちと踊りで鍛えた身体が目に入る。エルナは露出を抑えた服装で、整った顔と落ち着いた目つきが印象に残る。カイは二人を魅力的な成人女性だと短く意識するが、すぐ追手と魔物の位置、二人の負傷、逃げ道を確かめる。
  - 追手は、カイが前回高所から見た二人に加えて林の奥から一人が回り込み、姉妹の退路を狭めようとしている。魔物も二人へ迫っている。カイは見えた敵だけで全員と決めつけず、周囲の足音と移動先を目で追う。
  - リシェルはカイを味方と決めず、エルナを背後へかばったまま、助けるつもりか短く確かめる。カイは敵を止めるつもりだと答え、二人に負傷の程度と動けるかを尋ねる。救助の見返りは求めない。
- 人物の判断:
  - カイは負傷者を見つけたため、危険を確かめつつ救助に入る。二人を魅力的だと感じても、その認識を行動の理由や見返りの要求にしない。
  - リシェルはカイを信用せず、妹を自分の後ろへ置いて応答する。
- この場面で明らかになる情報:
  - 負傷者は二人で、追手と魔物に追い詰められている。高所から見えた二人以外にも追手がいる。姉妹は消耗しており、本来の戦闘力を出せない。
- 感情や関係の変化:
  - なし。

### 場面2: 戦場の形と退路を確かめる

- 時間 / 場所:
  - 夕方。林の開けた場所と、その外周。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - カイは姉妹と追手の間に入り、開けた場所の端へ動きながら、街道側へ抜ける道と、木立に隠れられる位置を確認する。敵を全員まとめて倒す前提を置かず、姉妹が動ける幅を作り、追手の回り込みを止めることを先に考える。
  - エルナは負傷したまま風の探知を短く使い、葉や枝の揺れ、足音の位置の違いから一人が外側へ動いたことをカイへ伝える。彼女の探知は敵の意図や身元を読むものではなく、回り込みの位置と近づく兆候を拾う。
  - カイは追手の武器の動き、魔物の接近、エルナが示した方向を見比べる。魔力知覚を短く集中して使うと、武器を持つ男の一人に魔力が偏って集まり、発動直前に乱れる感覚を得る。通常の視界で人数や位置を確かめたうえで、知覚だけから敵の正体や術の内容を決めない。
  - 知覚中に頭痛と視野の狭まりが強まり始める。カイは魔力の乱れをもう一度追うことを止め、姉妹の声と敵の動きを直接見て戦う判断へ戻る。
- 人物の判断:
  - カイは知覚で得られる情報に区切りをつけ、敵の人数や動きは通常の観察とエルナの報告で補う。
  - エルナは自分が探った情報を伝えるが、カイへ戦闘判断を丸ごと預けず、危険の兆候を共有する。
- この場面で明らかになる情報:
  - エルナの風の探知は回り込みの兆候を拾える。魔力知覚は敵の術の兆候を感じる手掛かりになるが、通常の視覚とは異なり、使い続ければカイの判断を損なう。
- 感情や関係の変化:
  - エルナはカイを信用したのではなく、危機を越えるために自分の情報を伝える。

### 場面3: 姉妹の行動で反撃の機会を作る

- 時間 / 場所:
  - 夕方。林の開けた場所。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - 回り込んだ追手が側面から近づくと、エルナは風で足元の落ち葉を散らし、接近位置をカイとリシェルに知らせる。同時に弱い風で武器の狙いをわずかに外し、姉妹の退路が塞がるのを遅らせる。彼女は負傷しているため、支援を続ければ消耗が増す。
  - リシェルは大きな炎を放たず、痛みをこらえて短い炎を敵の足元へ放つ。追手と魔物の注意が彼女へ向き、敵の列が崩れる。炎は敵を倒さず、追手の視線と歩調を乱すために使われる。
  - カイは二人の行動で生じた間に前へ出る。武器を持つ男が魔法を放つ直前、魔力の偏りが再び乱れたのを短く知覚する。頭痛と視野狭窄が強まる前に知覚を切り、男の腕と視線を通常の観察で追い、剣で発動を妨げる。
  - 別の追手が姉妹へ戻ろうとするが、エルナが伝えた位置を頼りにカイが進路へ割って入り、短い身体強化で相手の武器を受け流す。カイは魔法を連続して放たず、剣技で相手の動きを止め、必要な瞬間にだけ強化を加える。
- 人物の判断:
  - リシェルは妹の支援を受け、敵の注意を自分へ向ける役を自分で選ぶ。負傷のため炎の出力を抑える。
  - エルナは後方に留まるだけでなく、探知した方向を知らせ、短い風の支援で姉とカイの攻撃機会を作る。
  - カイは二人が作った機会を使い、魔力知覚を続けず、剣技と短い強化で敵の攻撃を止める。
- この場面で明らかになる情報:
  - 姉妹は負傷していても状況を判断して自分の能力を使える。カイは剣を主軸にし、知覚と魔法を必要な瞬間に限る。
- 感情や関係の変化:
  - 姉妹はカイの動きに合わせて次の行動を選ぶが、警戒は解いていない。

### 場面4: 追手と魔物を退ける

- 時間 / 場所:
  - 夕方。林の開けた場所から街道側へ続く斜面。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - 魔物がリシェルへ飛びかかり、追手がカイの後ろを取ろうとする。エルナは魔物の踏み込みを風でわずかにずらし、リシェルはその隙に身を引いて、残る力で短い炎を放ち魔物の進路を変える。
  - カイは魔物と追手の間へ入り、剣で魔物の攻撃を受け流す。魔法で魔物を一撃で倒そうとせず、姉妹が退ける道を空ける。追手の一人が再び武器を構えると、カイは先ほど感じた魔力の偏りと目の前の腕の動きを頼りに、武器へ踏み込みを合わせて攻撃を崩す。
  - 追手は負傷や隊列の乱れで姉妹を押さえ込めなくなり、魔物も攻撃を続けられず林の奥へ退く。カイは追跡者を深追いしない。頭痛が残り、姉妹も負傷しているため、その場で追手を全員倒すことより距離を取ることを優先する。
  - カイは姉妹の動ける範囲と街道側の見通しを確認し、短い距離だけ現場を離れる。追手が近くに残っている可能性は捨てない。
- 人物の判断:
  - 三人は相手を全滅させることではなく、姉妹が現場を離れられる時間と道を作ることを選ぶ。
  - カイは負傷と知覚の消耗を踏まえ、追撃しない。
- この場面で明らかになる情報:
  - 三人の協力で追手と魔物を一時的に退けられるが、追跡そのものは終わっていない。カイの知覚による頭痛と視野の狭まりは残る。
- 感情や関係の変化:
  - なし。

### 場面5: 疑いを残して同行を選ぶ

- 時間 / 場所:
  - 夕方から夜。林から離れた、街道を見張れる場所。
- 登場人物:
  - カイ、リシェル、エルナ。
- 起きること:
  - 追手の姿が見えない場所で三人は短く休む。カイは自分の頭痛を隠して平気なふりをせず、知覚を使いすぎたことと今すぐ追撃する余裕がないことを話す。姉妹の傷を確かめるが、二人が許す範囲で手当てをする。
  - リシェルは、カイが戦闘中に武器への魔力付与を止めて身体強化へ移り、短い魔法を使いながら戦い続けたことを父グレンの訓練の断片と比べる。幼い頃、グレンが余った魔力を体内へ戻して次の術へ使う感覚を教えていた。エルナも、カイの魔力の使い方が父の研究に似ていると考える。二人は自分たちがその感覚を知覚したとは言わず、類似の理由も分からない。
  - 姉妹はカイに、グレンを知っているのか、研究を見たことがあるのかを問いただす。カイはグレンと面識がなく、研究を盗んでいないと答える。魔力循環は自分の試行で身につけたものだと説明するが、姉妹はすぐには信じない。
  - カイは姉妹の魔法に関心を示すが、負傷中の今、詳しい説明や実演を求めない。救助したから情報を渡すよう迫ることもしない。リシェルはその態度と戦闘の結果を見て、次に敵が来た場合は妹を守る位置の一部をカイに任せる。エルナは追跡の兆候と自分の知る退路をカイへ伝え、次の進路を一緒に判断することを選ぶ。
  - 姉妹は、単独で進むより追跡をかわしやすく、互いに負傷している今の安全を保てる手段としてカイとの暫定同行を提案する。カイは、同行すれば自分も追跡へ巻き込まれることを確かめる。一方で、姉妹の魔法と父の研究に似た技術を知りたい気持ちがあり、二人が自分で同行を決めたことを受けて提案を受け入れる。
  - 三人は互いの事情をすべて明かさないまま、街道を避ける次の進路を決めて移動を始める。
- 人物の判断:
  - カイは研究への関心だけで姉妹を問い詰めず、同行の危険と自分の関心の両方を理解して受け入れる。
  - リシェルはカイを信用したのではなく、妹を守る役の一部を任せられると判断する。
  - エルナはカイへの疑いを保ちながら、追跡回避に必要な情報と進路判断の一部を共有する。
- この場面で明らかになる情報:
  - 姉妹は父の研究内容を完全には理解していないが、魔力循環の訓練の記憶がある。カイの技術との類似は分かっても、その理由は説明できない。
- 感情や関係の変化:
  - リシェルとエルナは警戒を保ったままカイへ限定的な判断を任せる。三人は安全とそれぞれの関心を理由に暫定同行を始める。

## 作者側の意図・設計理由

- 場面1ではepisode-001で見えた二人を追手の全員と誤認させず、林の奥で人数が増える可能性を具体化する。カイは通常の観察で人や位置を確かめ、魔力知覚を敵の人数確認に使わない。
- 姉妹による魔力循環の疑いは、カイの体内を二人が知覚する形では描かない。姉妹が知る訓練の記憶と、戦闘中に目撃した魔法の切り替えとの類似から疑う。
- 同行は恩義や即時の信頼ではなく、追跡を避ける必要、姉妹の警戒、カイの技術への関心が並ぶ中で各自が選ぶ。
