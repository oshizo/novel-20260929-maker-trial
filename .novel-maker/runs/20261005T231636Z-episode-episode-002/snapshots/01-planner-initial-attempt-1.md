# Episode Design: 追手から姉妹を救う

## 役割と境界

- Episodeの役割:
  - 追手と魔物に襲われている姉妹をカイが見つけ、三人それぞれの判断と能力を合わせて救助する。初対面での異性としての意識、姉妹の警戒と小さな評価、利害に基づく暫定同行までを描く。
- 入口:
  - カイが林の中で追跡の痕跡をたどり、助けられる見込みを確かめている。
- 出口:
  - 追手と魔物を退けて現場を離れた三人が、研究への疑いと追跡の危険を抱えたまま暫定同行を選ぶ。
- 視点 / 人称:
  - カイ一人称。全場面で視点を移さない。

## このEpisodeで読者に楽しませること

### 三人でなければ成立しない救助

- 読者が楽しめること:
  - 読者は、負傷した姉妹を追手が包囲しかけ、カイ一人では攻撃へ移る機会を失う状況から、エルナの危険察知、リシェルの自分の判断による攻撃、カイの観察と剣技が順につながって危機を脱する手応えを得る。初対面で連携の約束もない三人が、その場で互いの行動を使い、誰か一人の力では代われない結果を出す。

## 後の楽しさのために、このEpisodeで先に示すこと

### 姉妹が警戒を保ったまま相手を見極める

- 後で楽しませたいこと:
  - 他の男性から好意や誘いを受ける姉妹が、自分たちの意思でカイへ相談し、頼り、近くにいることを選ぶ特別扱いを読者が楽しめる。
- このEpisodeで先に理解させること:
  - 姉妹は救助された事実だけで相手を信用しない。カイが研究を盗んだのではないかという疑いを持ち続けながら、本人の行動と実力を見極め、必要な判断だけを任せる。

## 登場人物の目的と変化

### カイ

- この回で望むこと:
  - 負傷者を助けたい。ただし自分が負傷して旅と訓練を続けられなくなる事態は避けたい。救助の見込みと撤退条件を確かめて行動する。姉妹の魔法と、追手が用いる魔力の扱いにも関心を持つ。
- 妨げになること:
  - 追手と魔物の数・位置が分からず、視界の悪い林では包囲の危険がある。カイは魔力総量がやや少なく、魔力知覚を長く使うと頭痛と視野狭窄が強まる。姉妹は負傷と疲労で本来の力を出せない。
- 重要な判断の参照:
  - 場面1 / 場面2 / 場面3 / 場面5 / 場面6。
- 出口までに変わること:
  - 姉妹の危機を見過ごさず、三人の行動を利用して救助を成立させる。魔力循環を研究していたグレンは知らないが、姉妹がその研究との類似を疑っていると知り、研究と二人の魔法への関心を持つ。同行が追跡の危険を伴うと理解したうえで、暫定同行を受け入れる。

### リシェル

- この回で望むこと:
  - 追手から妹を守り、二人で現場を離れる。
- 妨げになること:
  - 負傷と疲労で炎魔法の出力や持久力が落ちている。妹を守るために注意を割きながら追手の狙いも見なければならない。救助者のカイにも、父の研究との関係がないか警戒している。
- 重要な判断の参照:
  - 場面2 / 場面3 / 場面5 / 場面6。
- 出口までに変わること:
  - カイの行動を見て、妹を守る役の一部を任せる。実力と見返りを求めない態度を小さく評価するが、研究への疑いは残す。追跡を避けるためカイとの暫定同行を選ぶ。

### エルナ

- この回で望むこと:
  - 追手の位置と進路を見極め、リシェルを守りながら安全に離脱する。
- 妨げになること:
  - 負傷と疲労があり、姉を支えながら追手と魔物の動きを探る必要がある。カイが父の研究を盗んだ、または関係している可能性を捨てられない。
- 重要な判断の参照:
  - 場面2 / 場面3 / 場面5 / 場面6。
- 出口までに変わること:
  - 追跡の兆候と自分が把握している退路をカイへ共有し、次の進路判断の一部を任せる。彼の実力を小さく評価するが、研究への疑いは残す。追跡を避けるためカイとの暫定同行を選ぶ。

### 追手の指揮役

- この回で望むこと:
  - 姉妹を捕らえるか討ち、グレンの研究へつながる情報を得る。
- 妨げになること:
  - 林の中で姉妹の位置を見失いかけており、負傷者二人を相手にするつもりで、加わったカイと姉妹の連携を見誤る。
- 重要な判断の参照:
  - 場面2 / 場面3 / 場面4。
- 出口までに変わること:
  - 攻撃を止められ、追跡を続けられないと判断して配下と魔物を退かせる。

## 場面順

### 場面1: 林の奥で襲撃を見つける

- 時間 / 場所:
  - 日没前。街道から外れた林の中。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - カイは足跡と血の跡をたどり、追手と魔物が二人の女性を林の窪地へ追い詰めている場面を見つける。姉妹は負傷して疲れているが、互いをかばいながら抵抗している。
  - カイは、リシェルが肌を見せる旅装を着こなし、追手の前でも視線を避けない姿と、エルナが露出を抑えた旅装で姉を支え、落ち着いた顔立ちを崩さない様子に目を留める。二人を魅力的な成人女性だと意識するが、すぐに追手の人数、距離、退路を確かめる。
  - 追手は姉妹を逃がさないよう左右から回り込み、魔物を前へ出して退路を狭めている。カイは姉妹が抵抗を続けていること、敵の位置、道へ戻る方向を見て、介入すれば逃げる機会を作れると判断する。
- 人物の判断:
  - カイは見た目への関心を引きずらず、助けに入る機会と撤退方向を優先して見定める。
- この場面で明らかになる情報:
  - リシェルとエルナは成人した姉妹で、負傷と疲労がある。追手と魔物に囲まれかけている。
- 感情や関係の変化:
  - カイは二人に異性として惹かれる印象を持つが、二人との関係はまだない。

### 場面2: 姉妹の知らせで包囲を避ける

- 時間 / 場所:
  - 続けて、林の窪地と周辺の木立。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - カイが横から追手へ仕掛けようとすると、エルナが風の探知で気づいた回り込みを伝える。敵の一部はカイを迎え撃つのではなく、道へ戻る退路を塞ごうとしている。彼女の知らせがなければ、カイは側面から挟まれていた。
  - リシェルは妹を背に守る位置を崩さず、負傷した体で短い炎を放って追手の注意を自分へ向ける。威力を競う攻撃ではなく、追手がカイへ向けていた動きと隊列を一瞬乱すため、自分で選んで放つ。
  - カイは二人が作った時間を使い、剣を抜いて敵との間合いを詰める。エルナは危険を見たら伝える役を続け、リシェルは無理に大きな炎を重ねず、妹を守る位置を維持する。
- 人物の判断:
  - エルナは自分の探知で得た進路情報をカイへ伝える。リシェルはカイに任せきりにせず、注意を引くための魔法を使う。カイは二人の行動を見て、単独で敵全員を追わず、攻撃を止めるべき位置へ進む。
- この場面で明らかになる情報:
  - 姉妹は負傷していても自分たちの判断で能力を使う。カイが間合いを詰める機会は二人の行動で生まれる。
- 感情や関係の変化:
  - 三人は互いを信用していないが、戦闘中に相手の行動を見て動き始める。

### 場面3: 魔力の乱れを見て攻撃を止める

- 時間 / 場所:
  - 続けて、窪地から退路へ続く木立。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - 退路を塞ごうとする追手の術者が、急いで魔力を集めて攻撃を放とうとする。カイは一度だけ魔力知覚を集中し、成形へ移る前に余った魔力が散り、術者の動きと発動の間が乱れていることを捉える。術の仕組みを解いたり、次の行動を確実に予知したりはしない。
  - 集中した知覚でカイの頭痛と視野狭窄が強まる。彼は観察を続けずに切り上げ、エルナが知らせた位置とリシェルが作った短い隙を使い、追手の攻撃が形になる前に剣技で間合いへ入る。身体強化を短く使って術者の構えと攻撃を崩し、退路を塞ぐ動きを止める。
  - 周囲の追手と魔物が隊列を保てなくなる。姉妹はカイが武器への魔力付与を止めて身体強化へ切り替え、短い魔法だけを使いながら戦い続けるのを見る。
- 人物の判断:
  - カイは知覚による症状が強くなる前に観察をやめる。読めた乱れだけで勝ちを決めつけず、二人が作った隙と自分の剣技で攻撃を止める。
- この場面で明らかになる情報:
  - カイは敵の魔力運用の乱れを感覚的に捉えられるが、観察には頭痛と視野狭窄の負担がある。敵の術を一目で理解したわけではない。
- 感情や関係の変化:
  - リシェルとエルナは、カイの力だけでなく魔法の切り替え方と戦い方にも注意を向ける。

### 場面4: それぞれの力で離脱の時間を作る

- 時間 / 場所:
  - 続けて、木立から林の斜面へ。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - カイは追手と魔物の正面を引き受け、剣技と必要な瞬間の身体強化で前進を止める。魔力を連発して敵を圧倒するのではなく、数を崩し、姉妹が抜けられる幅を保つ。
  - エルナは風の探知で別方向から迫る敵を知らせ、必要な範囲へ風の支援を使って追手の動きを遅らせる。リシェルは妹と離れず、自分の判断で短い炎を重ね、追手の注意をそらして隊列をさらに崩す。負傷による消耗があり、大きな術を続ける余裕はない。
  - カイは二人の合図と動きを受け、狙う敵と退く向きを変える。追手は攻撃を続けても姉妹を再び囲めず、魔物も統制を失って退く。指揮役は負傷者を追って損害を増やす危険を避け、配下を引かせる。
  - 三人は追手が戻る前に窪地を離れ、木立を抜ける。
- 人物の判断:
  - リシェルとエルナは追手を倒し切ることより、カイが作った離脱の機会を使う。カイも追撃せず、三人が現場を離れる時間を優先する。
- この場面で明らかになる情報:
  - 救助はカイの魔力だけでも姉妹の力だけでも成立しない。三人が相手の判断を使うことで追手と魔物を退けられる。
- 感情や関係の変化:
  - 姉妹は戦闘の結果をカイ一人の手柄とは見なさず、自分たちの行動が脱出を成立させたことを確かめる。

### 場面5: 救助の後も疑いを解かない

- 時間 / 場所:
  - 夕刻。追手の視界から外れた林の端。
- 登場人物:
  - カイ、リシェル、エルナ。
- 起きること:
  - カイは頭痛と視野の狭まりが残るため、魔力知覚を使い直さず、周囲の音と目印から追手が戻っていないことを確かめる。姉妹も消耗しているが、カイから距離を取り、武器を手元に置いたまま話す。
  - エルナは戦闘中に見た魔力の流れが、幼い頃に父グレンから教わった余剰魔力を体内へ戻す訓練と似ていたと話す。リシェルも父の研究との共通点を感じたと認める。二人はカイがグレンを知っているのか、研究を盗んだのかを問い続ける。姉妹は彼が自分たちと同じように魔力の流れを知覚したと考えているわけではなく、似ている理由も特定できない。
  - カイはグレンと面識がなく、研究を盗んだ覚えもないと答える。研究のことは知らなかったが、姉妹の魔法と父の研究には関心を持つ。救助の見返りに情報や感謝を求めず、負傷の手当てや次の移動を優先する。
  - リシェルはカイが妹を危険へ押し出さず、自分の判断を妨げもしなかったことを見て、次の移動では妹を守る役の一部を彼に任せると言う。エルナはカイへ追跡の兆候と自分が把握している退路を共有し、どちらへ進むかの判断を一部任せる。二人とも警戒と疑いは明言して保つ。
- 人物の判断:
  - カイは同行の話を急がせず、二人が危険を避けるために彼を使う場合の役割と限界を話し合う。リシェルとエルナは、救助を理由に信頼や好意を与えるのではなく、見た行動を基に必要な範囲だけ任せる。
- この場面で明らかになる情報:
  - 姉妹の父グレンは魔力循環を研究しており、二人には幼少時の訓練の記憶がある。カイはグレンと会ったことがなく、研究の詳細を知らない。魔力循環が似ている理由は未解明のままである。
- 感情や関係の変化:
  - 疑いは残るが、姉妹はカイの判断の一部を任せてもよいと考える。カイは二人の評価を歓迎する一方、それを信頼や好意の確定とは受け取らない。

### 場面6: 利害を確かめて暫定同行を選ぶ

- 時間 / 場所:
  - 夕刻。林を離れる前。
- 登場人物:
  - カイ、リシェル、エルナ。
- 起きること:
  - 姉妹は、負傷した二人だけで追跡をかわすより、カイと動く方が現実的だと判断し、当面一緒に進む案を出す。行動の理由は追跡を避けることと、カイの戦力を借りることであり、友情や復讐の共有ではない。
  - カイは姉妹が追われ続ける事情と、同行すれば自分も追跡へ巻き込まれる危険を確かめる。二人の魔法とグレンの研究への関心はあるが、それを口実に情報を要求しない。怪我を悪化させず、三人で追跡をかわす見込みがあると判断し、暫定同行を受け入れる。
