# Episode Design: 追手から姉妹を救う

## 役割と境界

- Episodeの役割:
  - 追跡中の姉妹をカイが救い、三人が互いの力と疑いを抱えたまま暫定同行を選ぶまでを担う。
- 入口:
  - カイが林の手前の見通しのよい場所から、追手と魔物に襲われている負傷者の姿を確かめる。
- 出口:
  - 追手と魔物を退けた三人が現場を離れ、追跡を避けるための暫定同行を始める。
- 視点 / 人称:
  - カイ一人称。カイが見聞きしたこと、身体で感じたこと、思い出したこと、考えて選んだことを通して描く。

## このEpisodeで読者に楽しませること

### 限られた魔力と剣技で姉妹を救い、二人から実力を認められるカイ

- 読者が楽しめること:
  - 魔力総量の少ないカイが、敵を力で押し切らず、エルナの伝える追手の動きとリシェルが作る隙、敵の魔力の乱れを結び付けて勝機を作る。魔力知覚に負担が出る前に観察を止め、剣技と短い強化で決着へつなげる判断の鋭さを楽しめる。
  - 救助の直後、研究を疑う姉妹が警戒を残したまま、実際の結果と見返りを求めない態度からカイを小さく評価し、判断の一部を彼へ任せる。助けたから無条件で信頼されるのではなく、価値ある相手から扱いがわずかに変わる満足を得られる。
- 誰についてのことか:
  - カイと、彼の判断・実力を評価するリシェル、エルナ。

## 登場人物の目的と変化

### カイ

- この回で望むこと:
  - 追手と魔物に襲われる人を助け、負傷と消耗を抱えたまま無理な戦いを続けずに現場を離れたい。救助後は姉妹の魔法と研究への関心を確かめ、同行する危険も考えたうえで次の行動を決めたい。
- 妨げになること:
  - 追手と魔物の動きを見失えば挟まれる。魔力知覚を続けると頭痛と視野狭窄が強まり、魔力総量も少ない。姉妹も負傷と疲労で本来の力を出せない。
- 重要な判断の参照:
  - 場面1、場面2、場面3、場面4。
- 出口までに変わること:
  - 姉妹の能力とグレンの研究に関心を持つ。追跡の危険を理解し、二人が選んだ暫定同行を受け入れる。

### リシェル

- この回で望むこと:
  - 妹を守り、追手と魔物から逃れて安全な場所へ移りたい。
- 妨げになること:
  - 負傷と疲労で普段の火力を保てず、追手に退路を塞がれかけている。初対面のカイが敵と無関係かも確かめられていない。
- 重要な判断の参照:
  - 場面2、場面3、場面4。
- 出口までに変わること:
  - カイの剣技と、見返りを求めない態度を小さく評価し、妹を守る役の一部を任せられると考える。研究への疑いと、妹を守る警戒は残る。

### エルナ

- この回で望むこと:
  - 追手の動きを読み、姉とともに退路を保って追跡を逃れたい。
- 妨げになること:
  - 負傷と疲労で探知や支援を長く続けられず、姉を支えながら追手を監視している。カイの魔力循環が父の研究に似ており、素性と目的を判断できない。
- 重要な判断の参照:
  - 場面2、場面3、場面4。
- 出口までに変わること:
  - 自分が伝えた敵の動きをカイが戦闘で使ったことを認め、次の進路判断の一部を彼に任せられると考える。研究への警戒は解かない。

## 場面順

### 場面1: 追手と負傷者の位置を確かめる

- 時間 / 場所:
  - Episode001の終わりから続く夕方。林の手前の見通しのよい場所。
- 登場人物:
  - カイ。離れた場所にリシェル、エルナ、追手、魔物。
- 起きること:
  - カイは茂みに身を隠し、血の跡の先を見渡す。追手は三人いる。二人が負傷した姉妹の正面におり、もう一人が林縁へ移ろうとしている。魔物二体も林沿いに見える。姉妹が長く持ちこたえられないことが分かる。
  - カイは姉妹を目にする。リシェルは片肩と腹部の見える踊り手風の旅装で、負傷してなお妹の前に立ち、痛みをこらえて追手を睨んでいる。肌の露出も、視線を受け慣れた堂々とした姿も目を引き、カイは彼女を華やかで色気のある女性だと感じる。隣のエルナは首元まで覆う落ち着いた旅装で露出は少ないが、整った顔立ちと静かな表情が印象に残る。姉を支えながら周囲を見張る姿にも、カイは別の魅力を感じる。二人とも成人した魅力的な女性だと意識した直後、彼は追手の位置と負傷の具合へ注意を戻す。
  - カイは林縁の斜面から姉妹へ近づけることと、街道へ戻る小道がまだ塞がれていないことを確かめる。敵の人数、近づく道、退路を確かめられたため、前話で決めた撤退条件には当たらないと判断する。ただし敵が動いた後の位置までは分からず、一人で正面から追手と魔物を引き受ければ挟まれる。街道へ戻る道を失わない位置から姉妹へ近づく。今は魔力知覚を使わない。戦闘で必要な短い観察の前に、頭痛や視野狭窄を起こしたくないためだ。
- 人物の判断:
  - カイは姉妹の動きと退路を確かめてから攻撃を決める。小道まで塞がれたら、前話で決めたとおり街道へ退く。
- この場面で明らかになる情報:
  - 追跡の理由と姉妹の素性はまだ分からない。
- 感情や関係の変化:
  - カイは二人に惹かれながら、助けられる見込みを測る緊張を強める。

### 場面2: 姉妹の判断を使って追手の狙いをつかむ

- 時間 / 場所:
  - 場面1の直後。林縁の斜面から姉妹のいる開けた場所へ近づく。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - カイが街道へ戻る小道を背にして近づくと、姉妹も彼に気づく。エルナは知らない男を警戒して問いかけるが、追手の接近で会話を続けられない。カイは助けに来たと伝え、二人の進路を塞がない位置で敵の動きを尋ねる。
  - エルナは負傷をこらえて風の探知を短く使う。周囲の兆候と合わせ、林縁へ移った一人が側面から退路へ回ろうとしていると読む。彼女はその方向と、姉妹の後ろに残る林縁の通り道をカイへ伝える。
  - リシェルは妹をかばう位置を崩さず、正面の追手が前へ出た瞬間、自分で時機を選んで短い炎を放つ。大きな術を使う余力はない。炎で正面の二人の注意を自分へ向け、隊列を乱す。
  - カイはエルナの知らせで回り込む一人の位置を知り、リシェルの炎で正面の二人がそちらを見たのを確かめる。姉妹の働きがなければ側面の敵へ踏み込む間に挟まれる。通り道を塞がれる前に、その一人の攻撃を止めると決める。街道へ戻る小道はまだ空いている。
- 人物の判断:
  - エルナはカイを信用したわけではないが、退路を守るために必要な情報は伝える。
- この場面で明らかになる情報:
  - エルナの風の探知とリシェルの炎は、この場面の「起きること」に記載。
- 感情や関係の変化:
  - カイは二人を守るだけでは勝てず、二人自身の判断が必要だと認める。

### 場面3: 魔力の乱れを見て退路を守る

- 時間 / 場所:
  - 場面2の直後。林縁と開けた場所の境。
- 登場人物:
  - カイ、リシェル、エルナ、追手、魔物。
- 起きること:
  - 側面へ回った追手が、エルナの示した林縁の通り道へ踏み込む。カイはその一人に魔力知覚を一度だけ集中させる。追手が武器を振り出す直前、魔力の流れが腕側へ偏る。カイは攻撃の軌道を避けて半歩ずらし、間合いを詰める。
  - カイは武器付与を刃へ短く通して相手の武器を受け流し、体勢を崩す。追手が通り道へ出るのを止めたところで、魔力知覚を切る。続ければ頭痛と視野狭窄が強まるためだ。武器付与も解き、発現に使わなかった余剰魔力だけを体内へ戻す。新たに魔力を集めるための呼吸を挟まず、身体強化へ切り替えて踏み込む。リシェルとエルナの視線が剣から足運びへ移るのにカイは気づくが、二人が何を考えたかは分からない。
  - 正面の二人が立て直そうとする。リシェルは妹の前を守ったまま、二度目の短い炎を正面の追手へ放つ。炎は相手を倒さないが、二人の視線が逸れる。カイはその間に回り込んだ追手を姉妹から遠ざける。正面の追手が通り道へ出ようとすると、身体強化した踏み込みと剣技で武器を弾く。
  - エルナは風の探知をもう一度だけ使い、林側から魔物二体が近づくことと、通り道がまだ空いていることを知らせる。カイは魔物に背を向けず、短い身体強化と剣技で一体ずつ攻撃を止める。追手と魔物は退き、三人が通り道を抜ける時間ができる。
- 人物の判断:
  - なし。カイの判断は「起きること」に記載。
- この場面で明らかになる情報:
  - カイの魔力知覚と余剰魔力の再利用は、この場面の「起きること」に記載。姉妹がカイの切り替えをどう受け取ったかは、まだ分からない。
- 感情や関係の変化:
  - カイはエルナの知らせとリシェルの炎がなければ挟まれていたと分かる。姉妹が危機を脱した安堵は、カイにも表情や動作から伝わる。

### 場面4: 疑いを残したまま同行を選ぶ

- 時間 / 場所:
  - 戦闘後まもなく。林縁から追跡を避けられる場所へ移動する途中。
- 登場人物:
  - カイ、リシェル、エルナ。
- 起きること:
  - カイは姉妹から距離を取り、負傷の具合を尋ねる。許可なく身体へ触れない。リシェルは何を見返りに求めるのか尋ね、カイは何も要求しないと答える。リシェルは炎で敵の注意を引いた後、カイが退路を守ったことを認める。そのうえで、彼の目的を問い続ける。
  - エルナは、カイが武器付与から身体強化へ息を置かずに移った様子を、父グレンから教わった余剰魔力を体内へ戻す訓練に似ていると話す。リシェルも同じように見えたと言い、なぜ父の研究に似た使い方ができるのか尋ねる。カイはグレンを知らず、研究を盗んだこともないと説明する。姉妹は答えだけでは疑いを解かず、エルナは類似の理由がまだ分からないと告げる。
  - カイは二人が使った探知と炎に関心を持つ。父の研究についても知りたいと思うが、負傷した二人へ今すぐ詳しい説明や資料を求めない。
  - エルナは自分で確かめた追跡の兆候と、林を抜ける二つの道の危険をカイへ伝える。戦闘中、彼が自分の情報を使って退路を守ったため、次の進路は追跡を見ながら彼にも判断してほしいと頼む。リシェルは、カイが妹に不用意に近づかず、見返りも求めなかったことを確かめ、妹の傷を見る間だけ反対側の警戒を彼に頼む。
  - 姉妹は追跡を避けるため、カイに暫定同行を提案する。カイは二人の探知と炎を見ており、彼女たちの父グレンの研究にも関心がある。一緒に行けば自分も追手に狙われると考え、危険を承知で受け入れる。三人は現場を離れる。
- 人物の判断:
  - リシェルとエルナは二人だけでは追手を避けにくいと考える。研究への疑いが残るため、今は安全に関わる一部の判断だけをカイへ任せる。
- この場面で明らかになる情報:
  - グレンが姉妹の父であることと、二人が研究との類似を疑うことは、この場面の「起きること」に記載。追手が何を求めているかは、カイにはまだ分からない。
- 感情や関係の変化:
  - なし。Episodeの出口に残る変化は「登場人物の目的と変化」を参照。
