# 文体方針（初回候補）

- 基本視点はカイ一人称とする。別の指定がない限り、場面ごとに視点人物を移さない。
- カイがその場で見聞きしたこと、身体で感じたこと、思い出したこと、考えて選んだことを通して書く。
- 説明は平易で具体的な日本語にする。比喩で印象を足すより、目に入った状態や身体感覚、実際の行動を書く。
- 魔法や道具の仕組みは、カイが気づいたことと試した結果に結びつけて示す。分かっていない仕組みを、カイや語り手が確定した知識のように説明しない。
- 会話と反応は人物の立場や関係に合わせる。計画にない完成台詞や細かな動作は本文で作る。

採用済みの本文サンプルはまだない。この文書は現在の作品方針と継続的な執筆条件から作った初回候補であり、作者の既存の好みを記録したものではない。
