# 物語冒頭のEpisode 0 / Episode 1設計

状態: 男性向けなろう / カクヨム系Web娯楽ファンタジーの物語冒頭を設計するための正本

本書は、物語冒頭で読者を主人公へ接続し、その作品の主要な楽しみへ早く入れるための規約である。

**frameworkは王道を既定値にする。** 作品方針や確定設定に明確な理由がない限り、Arc Plannerが独自に変則的な始め方を選ばない。王道から外したい作品は `story-direction.md` の冒頭方針で作者意図を明示する。

ここで示す `最頻出 / 頻出 / 少数` は厳密な市場統計の百分率ではない。男性向けなろう / カクヨム系Web娯楽ファンタジーを生成するときの**実務上の既定順位**を表す。

文章と言葉は [`language-policy.md`](language-policy.md) に従う。Planning上の役割は、比喩ではなく、実際に何を描くかで説明する。

## 1. 冒頭で最初に決めること

最初のArcでは、Episode一覧を作る前に次を決める。

1. この作品は異世界転生・異世界転移・現地主人公など、どの入口を持つか。
2. 異世界転生なら、後述する王道導入型のどれを使うか。
3. 独立した導入Episodeを `採用 / Episode 1へ統合 / 不採用` のどれにするか。
4. 読者が主人公へ接続したあと、最初の主要事件へどうつなぐか。

`使わない` を既定値にしない。一方、番号だけを理由にEpisode 0を機械的に追加もしない。

## 2. 異世界転生の王道導入型

異世界転生では、前世設定は単なる能力の由来ではない。多くの場合、**現代日本の読者を、前世の主人公を経由して異世界の主人公へ移す接続装置**として働く。

読者が少なくとも次を追えることを重視する。

- 日本にいたとき、主人公はどんな人間だったか。
- どのように転生した、または前世記憶に目覚めたか。
- 今世の身体、人格、家族、生活と前世の自分をどう捉えたか。
- 前世の視点を得たことで、それまでの世界や魔法がどう見え直したか。
- その結果、今世で何をしたい、どう生きたいと思ったか。

前世の学歴・職歴・家族歴を網羅する必要はない。しかし、これらを全部「前世由来の分析癖」の一言へ圧縮して、現在の仕事だけから始めることを王道扱いしない。

### 第1候補: `reincarnation-standard`

**頻出度: 最頻出 / 基本既定**

流れ:

`日本での前世 → 死亡または転生の境界 → 異世界で覚醒 → 状況把握 → 今世での最初の欲求・選択`

主に次を扱う。

- 日本での主人公を、読者が人物として掴める短い出来事。
- 死亡、事故、病気、転生を自覚する境界など、前世が終わったこと。
- 異世界の身体、家族、環境、常識への気づき。
- 日本の前世と今世の差を主人公自身が理解する過程。
- 二度目の人生をどう生きるか、この世界で何を試したいかという最初の選択。

作品方針や確定設定に別の強い理由がなければ、異世界転生ではこの型を最初に選ぶ。

### 第2候補: `memory-awakening`

**頻出度: 頻出**

流れ:

`記憶覚醒前の今世人格 → 前世記憶の覚醒 → 二つの人生の接続 → 世界の再認識 → 現在の欲求・選択`

転生後しばらく前世記憶なしで生き、途中で記憶が戻る設定では、一般順位が第2でも**設定そのものが明確な理由になるため、この型を優先する。**

主に次を扱う。

- 記憶が戻る前の今世の主人公が、どんな家庭・常識・人格で生きていたか。
- 何をきっかけに、どのように日本での前世を思い出したか。
- 前世の人格が今世の身体を乗っ取ったように処理せず、主人公自身が二つの人生の連続性や違いをどう受け止めたか。
- それまで当たり前だった言葉、魔法、身分、生活、世界を、前世記憶を得た後にどう見直したか。
- 前世の視点と今世の経験が合わさり、現在の目的、能力観、旅、生き方がどう生まれたか。

記憶覚醒が物語開始より前の出来事でも、読者接続に重要なら「昔のことだから省略」で落とさない。現在場面からの短い回想、冒頭の過去場面、時系列での導入など、読みやすい形で必要な体験を見せる。

### 第3候補: `current-first-early-reveal`

**頻出度: 頻出だが第1・第2より下位**

流れ:

`異世界での強い現在事件 → 冒頭近辺で前世・転生を回収 → 現在の自己と接続`

次のような明確な理由がある場合に選ぶ。

- 作品の中心的な事件や関係を最初の数ページで始める方が明らかに強い。
- Directionが現在事件から始めることを指定している。
- 前世を少し遅らせること自体に、読者体験上の意味がある。

現在から始めても、前世・転生・今世の自己接続を何話も後まで放置しない。冒頭近辺で回収する。

### 第4候補: `current-only-exception`

**頻出度: 少数 / 例外**

転生過程や記憶覚醒をほぼ描かず、現在の主人公に前世由来の知識・思考だけを残す型。

frameworkの既定では選ばない。次のような作者意図を `story-direction.md` で明示した場合だけ選ぶ。

- 前世は読者接続ではなく、能力設定の補助にすぎない。
- 転生の事実を後の謎として扱う。
- 現在から始めるテンポを最優先し、前世の自己接続を意図的に省く。

単に「説明を短くしたい」「現在の行動で性格は分かる」だけでは、この例外を選ぶ理由にならない。

## 3. 転生以外の冒頭

異世界転移なら、基本は `日本での主人公 → 転移 → 異世界を初めて認識 → 最初の選択` を優先する。

現地主人公なら、前世との接続は不要なので、現在の生活、欲求、判断、能力と制約、最初の主要事件への接続を行動で見せる。

作品方針が別ジャンル・別読者体験を指定している場合は、そちらを優先する。

## 4. 独立導入Episodeの採否

導入型を決めた後、その内容を独立Episodeへ置くか判定する。

独立した導入Episodeを採用しても、opening専用のArcは作らない。**冒頭導入は最初のArcの一部として扱う。** この場合、最初のArcの `入口` は冒頭導入Episodeが始まる時点を指し、最初の主要事件が始まる時点とは区別する。

- `採用`: 最初のArc内に独立した導入Episodeを置いて主人公へ接続してから、同じArc内で最初の主要事件へ入る。
- `Episode 1へ統合`: 最初の主要事件の前半で必要な主人公接続を行い、そのまま事件へ入る。主要事件を過密にしない。
- `不採用`: 主要事件そのものだけで必要な主人公接続が十分に成立する場合に限る。

異世界転生で `不採用` を選ぶ場合でも、選んだ王道導入型が別の形で冒頭から成立している必要がある。

また、**導入は必ず一話で終える必要はない。** `前世 → 転生 → 幼少期 → 現在` や `今世人格 → 記憶覚醒 → 世界の再認識 → 現在` を一話へ圧縮すると人物接続が壊れるなら、複数Episodeへ分けてよい。その場合も導入Episode群は最初のArcに含める。ただし作品の主要なPromiseを不必要に遅らせない。

## 5. Episode 0 / 冒頭導入セットの役割

### 転生作品

Episode 0または冒頭導入セットは、単なる「主要事件前の小さな仕事」ではない。

主に次を担う。

- 読者が前世の主人公を人物として掴む。
- 転生または記憶覚醒を主人公と一緒に経験する。
- 前世と今世の自分の関係を理解する。
- 主人公の目を通して異世界を初めて、または改めて見る。
- 現在の欲求、価値観、能力の使い方がどこから来たかを理解する。
- 最初の主要事件で主人公を追いたい状態を作る。

その後に、仕事、訓練、小さな問題解決などを置いて現在の能力を実演してよい。しかし、能力実演だけで転生導入を済ませた扱いにはしない。

### 現地主人公など

主に次を扱う。

- 現在の生活や仕事。
- 小さな欲求、楽しみ、不満、避けたいこと。
- 判断の仕方、口調、価値観、人との距離。
- 主人公固有の能力・技能・強みと、その限界の一部。
- 最初の主要事件へ自然につながる移動、依頼、発見、選択。

## 6. 最初の主要事件で行うこと

冒頭導入の次のEpisodeでは、作品方針やOverallで重要な最初の事件、出会い、問題を起動する。

- 導入で見せた判断、欲求、能力、制約、前世/今世の視点を実際の出来事で使う。
- 作品が約束する主要な楽しみを、可能なら小さくても一度返す。
- 主人公の状況を変え、次へ進む具体的な理由を作る。

冒頭導入セットを読み終えた時点で、少なくとも「この主人公は誰で、なぜこの目で世界を見ていて、何が始まった話なのか」が分かることを目指す。

## 7. Story Craftで確認すること

最初のArcでは、通常の読者報酬に加えて、導入を時系列で読む。

### 共通

1. 誰が主人公か分かるか。
2. 主人公が何を望み、どう判断するか分かるか。
3. 能力・技能の特徴と制約が必要な範囲で分かるか。
4. 導入で見せたことが最初の主要事件へつながるか。
5. 世界設定の説明だけで進んでいないか。
6. 主要な作品Promiseを遅らせすぎていないか。

### 異世界転生

さらに次を確認する。

1. 読者が「前世の誰」から「今世の誰」へ接続できるか。
2. 転生・記憶覚醒が一行の設定説明だけで済まされていないか。
3. 記憶覚醒前の今世人格があるなら、それを消して「日本人が別人の身体を乗っ取った」ように見せていないか。
4. 主人公自身が前世と今世の関係をどう受け止めているか分かるか。
5. 前世の視点を得たことで、この世界や魔法がどう見え直したかを読者も体験できるか。
6. その認識が現在の欲求、能力の使い方、旅、生き方へつながっているか。
7. 第2候補以下を選んだ場合、CanonまたはDirectionにその型を選ぶ具体的な理由があるか。
8. `current-only-exception` を、単なる省略やテンポ都合だけで選んでいないか。

この接続が欠けるなら、現在の能力実演が上手くても冒頭Story CraftをPASSにしない。

## 8. 避けること

### 世界設定の講義

国、魔法体系、歴史、身分制度などを、主人公の経験や判断と関係なくまとめて説明しない。

### 主人公プロフィールの読み上げ

名前、年齢、能力、前世、性格、目的を、出来事と切り離して一覧しない。

### 前世の年表

前世の経歴を最初から最後まで説明しない。現在の自己接続に必要な人物像・経験を選ぶ。

### 「説明を避ける」ことを理由に転生接続まで消す

前世・転生・記憶覚醒を説明臭くしたくないからといって、読者が主人公へ接続するための出来事そのものを省略しない。**情報量を絞ることと、入口を消すことは別である。**

### 記憶覚醒前の人格を消す

途中で前世記憶が戻る設定では、覚醒前の今世人格を単なる空の器として扱わない。Canonが別の仕組みを定めない限り、同じ人物の人生へ前世記憶が加わったものとして、本人がどう受け止めるかを描く。

### 後半の場面を理由なく先に見せる

最終決戦などを先に見せる構成は、その作品で明確な効果がある場合だけ使う。

## 9. Planningでの扱い

Arc Plannerは最初のArcを作るとき、本書を読んで次を親agentへ返す。

- `opening_sequence_pattern`: 選んだ導入型。異世界転生なら原則として `reincarnation-standard / memory-awakening / current-first-early-reveal / current-only-exception` のいずれか。
- `opening_sequence_decision`: `採用 / Episode 1へ統合 / 不採用`。
- `opening_sequence_reason`: Canon / Directionと照らした短い理由。第2候補以下なら、なぜ第1候補ではなくその型かも書く。

親agentはこれらをrun traceとPR本文へ記録する。

Directionに王道から外す明示指定がなく、Canonにも別型を選ぶ理由がない異世界転生では `reincarnation-standard` を既定とする。

Canonが「今世で一定期間生きた後に前世記憶が戻る」と定める場合は、その設定を理由に `memory-awakening` を選ぶ。

Arc Plannerは、選んだ導入型が必要とする内容を一話へ無理に押し込まない。必要なら冒頭導入セットを複数Episodeにする。

独立導入を採用した場合、**最初のArcの入口は冒頭導入セットの最初のEpisodeが始まる時点に置く。** 最初の主要事件が後のEpisodeから始まるなら、その開始はEpisode一覧の役割・入口として表し、Arc全体の入口を「冒頭導入後」に置かない。opening専用の別Arcは作らない。

通常Episodeは従来どおり一度に1つだけ扱う。複数Episodeを冒頭導入セットとして計画する場合でも、Episode Design / Writer Brief / 本文は各Episodeの責務境界に従って作る。

## 10. 作品方針との関係

王道はframeworkの既定値である。

個別作品で王道から外す場合は `story-direction.md` の `冒頭方針（任意。王道から外す場合だけ）` に、採用する型と理由を書く。

Directionが未指定だから自由に変則型を選べる、という意味ではない。**未指定なら王道へ戻る。**

ただしCanon自体が「途中で前世記憶が戻る」等の構造を確定している場合は、そのCanonに適合する王道型を選ぶことは例外ではない。

## 11. 参考にした実務知見

固定公式ではなく、冒頭設計を考えるための参考とする。

- カクヨム公式の作家インタビューや創作講座では、1話目を世界観説明だけで終わらせず、読者の興味を引く要素や主人公の目標を早めに示す考え方が繰り返し紹介されている。
- 異世界転生の代表的な商業化作品には、日本での前世から死亡・転生・異世界での状況把握へ進む導入や、今世の身体で目覚めて前世との違いを認識する導入が広く見られる。

これらを個別作品より上位の絶対則にはしない。一方、作者指定のない生成で変則型を優先する理由にも使わない。
